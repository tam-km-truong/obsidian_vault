# Web Development Best Practices & FAIR Principles

## FAIR Principles in Scientific Software
- **Findable:** Clear persistent identifiers (DOIs via Zenodo), discoverable metadata.
- **Accessible:** Open protocols, standard REST APIs.
- **Interoperable:** Standard data formats (FASTA, Newick, TSV).
- **Reusable:** Permissive open-source licenses, documentation, containerization (Docker/Singularity).
